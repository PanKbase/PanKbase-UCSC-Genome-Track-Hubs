Candidate cis-regulatory element (cCRE) to gene links by cell type

  • Links between snATAC-seq cCREs and genes predicted with the Activity-by-Contact (ABC) model, one track per pancreatic cell type ; each cell type shows its ATAC-seq signal (bigWig), ATAC peaks (bigBed) and ABC links together (signal and peaks as in 01-ATAC-Seq)
  • Each item is an arc from the cCRE (300 bp; class promoter, genic or intergenic) to the transcription start site of the linked gene
  • Item name is the gene symbol; the score is the ABC score x 1000 (capped at 1000); the full ABC score is shown on the item details page
  • A gene can link to many cCREs, and a cCRE to several genes

Cell types by tracks:

  • Alpha, Beta, Gamma, Delta: islet endocrine cells
  • Acinar, Ductal, MUC5B Ductal: exocrine cells
  • A Stellate, Q Stellate: activated and quiescent stellate cells
  • Endothelial, Immune, Schwann
